# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Use GitHub's private vulnerability reporting instead:
👉 [Report a vulnerability](https://github.com/laxminarayanaboga/project_hr/security/advisories/new)

Alternatively, email: laxminarayanaboga4079@gmail.com

Include as much detail as possible — steps to reproduce, affected versions, and potential impact. I aim to respond within 48 hours.

## Supported Versions

This project is under active development. Only the latest version on `main` is supported.

| Version | Supported |
|---------|-----------|
| `main`  | ✅        |
| older   | ❌        |
